+ **食堂卫生方面提案**
    + **A同学提案：**
        + 提案内容涉及食堂汤桶摆放位置及汤碗清洁问题。高一冬天时因高年级后吃饭，盛汤时汤常已凉，口感不佳，且汤中偶尔出现异物；同时观察到汤碗有时不够干净。建议学校整体清洁汤碗或更换更好的汤碗，并将汤桶从人流量大、易灌风的出口位置移至饮水机附近等无人流量且不灌风处。提案提交后，上周四、周五发现汤碗已更换为特别干净的碗，汤桶也已摆放至饮水机位置，对校领导及校职工的支持与帮助表示感谢。
    + **B同学提案：**
        + 发现食堂盛汤的白色碗多未清洗干净，自己盛汤时需挑约10个碗才能找到一个无黑色沫状污渍的碗。提案提交后，于下周一下午抽了10个碗进行清点，发现其中基本只有1个是好的，且不少碗存在小的裂缝，至少约10个碗有裂缝问题。认为裂缝既不美观、寓意不好，也存在卫生问题，建议更换碗具，并严加监督洗碗过程。
    + **学校领导回应：**
        + 上周提案提交后已及时进行跟踪与整改。餐具属于密胺餐具，使用时间已有1学期或1年以上，因一天使用3次、利用率高，高温消毒时外层保护膜自然脱落。上周提案后已更换为红色碗，该批碗为去年采购的几千个碗，因新碗前两天才到货故及时替换。后续将加强洗刷、消毒过程管理，安排专人每日在消毒后进行人工分拣，检查碗是否有消毒死角、残渣等问题，目前相关工作已安排到位，该更换的更换、该替换的替换。
        + 学校方面会加强餐具消毒，同时请同学们帮忙宣传，提醒大家放餐具时轻拿轻放，减少磕碰损耗，因为大部分同学放餐具时是扔着放的，对餐具损耗较大。

        + 主食统一定价15元，无差异化，不论炒饭、面条还是意大利面均为15元。查询北京市政府采购竞争性磋商文件，北京四中食堂采购投标表规定早餐自助餐标5元/人、午餐自助餐标15元/人、晚餐加班餐自助餐标15元/人，认为主食15元一份即根据此餐标设计，但按此餐标只能拿一份主食，不能再添加其他东西，或只能拿两份薯条，对高中男生而言分量吃不饱。

    + **学校领导回应：**
        + 从9月1号开始食堂已全面转为自营，学生看到的报表信息均为自营之前的信息，现已不作数。转为自营后，米面油肉蛋奶等食材采购均从指定集采平台采购，如奶的价格，学校进多少钱就卖多少钱，平台调整价格学校就调整价格，不存在利润问题。
        + 满意度调查正在准备中，计划在期中考试之后组织各年级做用餐满意度调查，因转为自营后需运行一段时间让大家感受适应。
        + 沟通机制方面，食堂有意见本，还有学生会管委会的微信群渠道（邱老师负责），若觉得沟通不顺畅或反馈慢，也可直接与食堂老师沟通，后续会把食堂老师办公室电话放在食堂里，手写、微信、电话均可。
        + 自营解释：收入为大家交的餐费，支出分两部分，一是食材从平台采购、平台什么价格就按什么价格（上级指定），二是食堂工作人员的用工成本（劳务费），其余部分均用于食材加工制作让学生吃到嘴里。

        + 主食定价问题：食堂主食定价（面条、炒米饭等）是综合考虑成本核算的结果。中午每波就餐700多人、总就餐时间20分钟，若品种过于分散、选择余地太多，吃饭时间跟不上，因此每天准备5种盖饭、面条、炒饭等提前备好的品类以减少排队速度。学校规定食材投入为65%，35%为人员工资，相当于10块钱有6块5的成本。若进入每个菜场决定价格，有的菜会高过15元、有的会低，因此取中间值按直接投入入股率65%定价。校长指出学生最关注的是直观看到15块的性价比，认为在性价比和服务质量、成本核算方面还有改进空间。
+ **食堂菜品方面提案**
    + **D同学关于恢复酱肉包和果汁的提案：**
        + 三年前在道园校区吃学校早餐的酱肉包非常好吃，但现在味道变了，完全不一样了。食堂阿姨曾在其课间操时帮忙热酱肉包，非常好吃。后来听说做酱肉包的师傅离开了，希望恢复原来的酱肉包。
        + 之前学校有苹果汁、优酸乳，三年前还有咖啡、复合果汁、NFC芒果汁、大瓶绿豆汁、玉米汁、双柚汁等，都非常好喝，但现在品种没有原来丰富了。
    + **E同学关于增加水果和果汁的提案：**
        + 果汁减少可能是因为家长不想让孩子喝含添加剂的饮料。入学教育时在道园校区有免费西瓜等水果，之前所在学校无食堂、由送餐公司供饭，一周5天至少2到3天有苹果、香蕉、橘子等各种水果，但到四中后发现没有水果。水果含维生素，对学生大脑和身体发育有帮助，周围同学都很想吃水果，建议在卖酸奶的地方增加卖水果，如按个售卖苹果，进行合理定价，增加选择。
    + **学校领导回应：**
        + 饮料问题：现在都是从平台采购，平台上目前只有奶制品，没有其他饮料，暂时无法提供。将来会向平台反映，建议增加健康饮料品种，但学校只能建议，因为平台的事不由学校决定。
        + 水果问题：水果售卖没有问题，昨天已开始售卖，目前暂定中午卖苹果、晚上卖梨，后期会增加橙子、香蕉等。因学生食堂营业执照不允许冷荤凉菜，水果不能分切售卖，只能整个售卖。
        + 酱肉包问题：会想办法联系厨师，询问配方，想办法调整，满足学生的合理诉求。
+ **食堂窗口开放方面提案**
    + **F同学提案：**
        + 提案关于食堂窗口开放问题。因自己容易饿，下操后常去食堂吃饭，之前每次排队时间太长，窗口一般只开2个，等待时间较长。若不跑步抢靠前位置可能没时间吃甚至没时间买，大家争相抢饭可能引发危险。建议多开几个窗口，看到好几个台子都可以架售卖机器，建议加到4个或5个窗口，缓解排队情况、减少受伤概率。目前问题已得到较好解决，现在每次开4个窗口，排队情况不严重，基本10点左右大家都能吃上早餐。
    + **学校领导回应：**
        + 上周提案后已进行调整。与黄老师及学校老师商量，尽量中午多开窗口。目前有4台卡机，可安排6人同时售卖；下周学校又订了2台卡机，将分为6个窗口、8人同时售卖。因从外面结算台走有时间段限制，9:50之前10:00要切换早餐和午餐信息，行不通，所以只能增加卡机和人员。本周为4台卡机6人售卖，下周将增至6台卡机8人售卖，争取10分钟内基本不用排队。
        + 提醒同学们注意早餐食品保质期，糕点类一般到不了第二天，酸奶储存条件为2到6度，不能脱离冷藏时间过长，超过3小时就会变质。建议以展板或常识宣传形式在排队时进行宣传，让大家了解酸奶需保持冷藏温度，冬天还好，夏天问题更严重。
+ **校长总结讲话**
    + **食堂问题总结：**
        + 酱肉包问题本质是口味问题，会想办法解决，但不能完全依据个人口味，需满足北方学校多数人的口味，这背后是质量（含口味）如何更满足学生需求的问题。
        + 水果可增加售卖，但受限制不能切分小的来卖。西瓜因季节原因可切小块售卖。
        + 果汁问题：现在家长可能都不太愿意孩子喝市面上果汁。曾做过决定停掉羊肉串，因为学校是教育场所，引导大家健康饮食是第一位的。
        + 建议同学们一定要吃好早饭，否则前两节课到9:00左右就不行了，下操加餐问题已得到很好解决。
        + 食堂卫生是老生常谈的问题，不是今天答应了就一切都好了，不是换了碗就都好了。食堂食品安全和卫生问题没有客观原因，只有学生的主观认识和客观标准，做食堂就得好好的把这些问题解决。
        + 菜品信息问题：今天在沟通，要提供更明确的信息，如菜品构成、是否含过敏原、口味（辣口等）等重要信息。现在过敏的同学挺多，如蘑菇过敏等，这类问题需要重视。
        + 食堂学校经营背景：大宗食材必须经过政府批准的平台购买，平台有就能买、没有就买不着。好处是质量有保障、价钱公道，不好处是个性化要求很难满足，这是刚执行的政策，学校也在反馈意见。
        + 食堂必须非盈利，员工工资占35%，入口率60%左右，有的校区达到70%多，说明超过了，未来要达到平衡。但这是宏观平衡，不能用来解决学生直观感受到的性价比问题，如一份炒饭值不值15块钱，性价比要微观来看待。
    + **校长会客厅机制：**
        + 校长会客厅后续还有卫华书记和几个校区校长负责。学校是大家的，沟通机制特别关键，有问题提出来，也许两句话就解释清楚，能解决的第一时间解决，不能解决的一定要告诉大家原因。
        + 校长会客厅第一项原则是实事求是，大家实事求是的提意见，学校实事求是的反馈，否则会客厅就失去意义。
        + 期待同学们提建设性意见，从自己的角度提出解决问题的方法，学校判断可行性。学校也有一些课程，希望大家共同改造学校中不令人满意或不符合学生需求的地方，让同学们心情愉悦、专注于学业和校内活动。
        + 校长会客厅是新一届学生会特别棒的一件事，把学生意见建议和学校直接面对解决，感谢学生会。
+ **自由交流环节**
    + **高一新生补充提案：**
        + 作为高一新生，所在班级同学对校园比较陌生，对食堂菜品是否加辣、口味如何不太了解。以学校鸡排为例，在食堂吃了一个多月，发现鸡排主要有两种：一种是不辣的，里面有时有芝士馅流心，很香很好吃；另一种是辣的，对吃不了辣的同学难以接受。但辣与不辣通过外观看不出来，每次买鸡排像在做赌博，有一定概率完全吃不了，浪费食物。建议对鸡排等有辣与不辣属性的食品做清晰标注。
        + 校长回应：该问题立行立改，要给阿姨做好培训。有同学反映因过敏询问阿姨汉堡里是鸡排还是鱼排，阿姨说是鸡排，吃了后过敏，实际是鱼排，因对鱼过敏。信息对不上，只写汉堡，需立即整改，更全面细致。
    + **会议结束：**
        + 主持人宣布校长会客厅活动结束，感谢各位领导老师的支持和各位同学的参与。食堂汤经理可加微信，有问题可随时沟通。校长因解决大家吃饭问题一直未吃饭，会议在周三下午结束。

# 会议总结
